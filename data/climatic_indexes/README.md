# Climate Index Data

Small public climate-index files used by the paper-specific figure scripts.

## Column Formats

The current ENSO index file is a whitespace-delimited NOAA-style text file. The columns in this format are:

`YR`, `MON`, `NINO1+2`, `ANOM`, `NINO3`, `ANOM`, `NINO4`, `ANOM`, `NINO3.4`, `ANOM`

The current NAO index file is a whitespace-delimited year-month-value text file. The columns in this format are:

`year`, `month`, `nao`
